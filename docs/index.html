Phase-Contrast Clean-Up

Phase-contrast microscopy wraps every cell in a bright halo that confuses downstream segmentation. Drag the parameters below and this page re-runs the project's suppression pipeline — Difference-of-Gaussians then CLAHE — on the image in front of you, in your browser, updating the picture and the numbers as you go.

This page reads docs/samples/manifest.json. Generate it with:

python data/generate_synthetic.py --num 100 --size 256
python scripts/make_demo_assets.py --count 6

Then commit docs/samples/, or preview locally with python -m http.server -d docs 8000.

Result

The three left panels are computed here, live, as you drag. The U-Net column is precomputed — 31M parameters is a ~124 MB download and far too slow for WebAssembly, so it is rendered ahead of time and served as an image.
